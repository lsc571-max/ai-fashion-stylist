🔑 Gemini API 키 발급받기

API 유료 생성은 사용자가 확인한 뒤에만 호출합니다. 예상 비용은 1K 이미지 1장 출력 기준의 참고값이며 입력 토큰·세금·실제 환율 등이 더해질 수 있습니다. 모델 요금은 변경될 수 있습니다.
이 기기에 키 기억하기는 브라우저에 암호화되지 않은 키를 남깁니다. 공용기기에서는 선택하지 마세요. 공개 서비스에서는 서버를 통해 키를 보호해야 합니다.
